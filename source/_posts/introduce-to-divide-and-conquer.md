{% note info %}
-现在我们来玩一个游戏：
-假如我从0到100里面选了一个数字， 你来猜我选的数字
我根据你猜的数字告诉你猜大还是猜小了
-怎么样可以尽可能快的猜到？
{% endnote %}

思路一
从0到100, 一个一个猜， 很显然， 最后肯定能猜到，但是如果这个数字是100, 你要猜测的次数将会高达100次！

思路二
注意到游戏规则里面说明会告诉你猜大还是猜小， 比如我选了72, 
你猜50, 我告诉你猜小了， 那么就可以直接排除小于50的所有数

每次猜测都可以排除比我们猜测的数字大或小的所有数字，
要尽可能的排除不可能的情况， 我们选择中间值可以在最坏情况下最快的猜对 （证明：假如如果选了比中间值大的一个数字55， 而答案是小于55这个数字的， 接下来我们要在0到55里面选， 但是如果选的是50, 无论偏大偏小我们下一次都是只在50个数字里面选， 数字越少我们选对的概率越大， 所以选中间值可以在最坏情况下最快猜对）

同时除了上一节我们介绍的for循环，我们介绍一下另一种循环的方式
while 循环。 正常情况下for循环常用于迭代， 而while在不知道迭代次数但是知道终止条件时用的更多。

{% note info %}
```python
ans = input()
guess = input()
guessCount = 1

while ans not equals to guess :
    if guess > ans:
        print("猜大了\n")
    else if guess < ans :
        print("猜小了\n")
    else 
        print("猜对了\n")
    guess = input()
    guessCount += 1
print(guessCount)
```
{% endnote %}

更一般的， 如果我们要在一个给定范围的数据里面找到猜的数， 我们同样可以用这个思路， 我们把这种思路叫做二分法

二分法有个前提， 这个数据得是有序的， 然后我们才可以根据偏大偏小来排除(如果不满足有序， 我们需要先排序)
{% note info %} 
练习：
    假如现在输入了low， high 分别表示要猜测数据的最大和最小值
    以及一个数组存储了从low 到 high的数据, 要从这个数组里面找到我们要寻找的target, 设计程序使得能够在最坏情况下找的最快


   - /** 提示* 我们让程序模拟这个过程， 每次都猜中间值 */

   {% note info %}
   ```python
    low = input(), high = input(), target = input()
    cnt = 0
   
    while low <= high :
        mid = low + (high - low) / 2
        if mid == target :
            break
        if mid > target :
            high = mid - 1
        else 
            low = mid + 1
        cnt += 1
    
    print(cnt)
    ```
