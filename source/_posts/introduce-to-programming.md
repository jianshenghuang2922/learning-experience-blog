- 我们先从线性数组开始
-假如我们要存储1到100这100个数字
-要存储多个同类型数据：
-    int a = 1
-    int b = 2
-    int c = 3
-    int d = 4
-    int e = 5
-    ......
    
    -有100个数据， 这么写将会很麻烦， 因为我们引入了很多变--量， 我们不希望有这么多变量来增加我们的负担
    -所以我们引入数组来存储同类型的变量
    -
    -    int a[100];
    -   从零开始作为起始下标
    -    a[0] = 1
    -    a[1] = 2
    -   a[2] = 3
    -    a[3] = 4
    -    a[4] = 5
    -    a[5] = 6
    -    ......
    -你发现了， 这样在存储数据上方便了很多， 不需要引入多个变量


    - 还可以再优化别的方面吗？
    - 比如， 我们明显发现了这个数组是有规律的
    - 为了避免重复书写， 我们引入循环的概念
    - for index from 0 to 99
    -  a[index] = index + 1
    -  在c 或 c++ 里就是
    -  for (int i = 0; i < 100; i += 1) {
    -      a[i] = i + 1;
    -  }
